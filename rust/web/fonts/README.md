# Fonts

`Inter.var.woff2` is Inter 4.0 (by Rasmus Andersson, SIL Open Font License 1.1, see
`LICENSE-Inter.txt`) as a single variable font with weight and optical-size axes,
covering Latin, Cyrillic and Greek. It is the exact file Frappe UI ships, so the page
matches Frappe's typography; `styles/app.css` also takes Frappe's settings (optical size
24) and type scale.

Taken from the `frappe-ui` npm package, version 0.1.278, `src/fonts/Inter/Inter.var.woff2`
(SHA-256 `d30c3bd04e08f990b25152ab3b7f7550c0ba35f72bf8ad1c7cd791d16d94526e`):

```bash
npm pack frappe-ui@0.1.278
tar -xzf frappe-ui-0.1.278.tgz package/src/fonts/Inter/Inter.var.woff2
```
