# Веб-страница

Страница одна и та же, где бы она ни работала: на
**[tools.eidox.io/sap-bin-parser](https://tools.eidox.io/sap-bin-parser/)**, на вашем
компьютере ([приложение](cli.md)) или в [вашем собственном контейнере](docker.md). Ничего из
того, что вы конвертируете, не сохраняется ([как это устроено](privacy.md)).

![Просмотр выгрузки: таблица, геометрия записи и первые записи](../images/inspect.png)

## Перетащить, посмотреть, конвертировать

1. **Перетащите** выгрузку на страницу или выберите файлы или папку.
2. **Посмотрите.** Меньше чем за секунду страница показывает таблицу, число шардов, число
   записей, геометрию записи и первые 20 записей. Для этого она читает только первые 4 МБ и
   последние 256 КБ файла.
3. **Конвертируйте.** Выберите CSV, CSV для Excel, Parquet или JSON Lines и нажмите кнопку.
   Страница показывает скорость в записях в секунду и оставшееся время, а результат
   попадает в загрузки.

## Конвертация в браузере

Там, где браузер это позволяет, страница делает всё сама: тот же движок, что у сервера и
приложения, скомпилированный в WebAssembly, работает в фоновом потоке страницы. Выгрузка
читается с вашего диска и никуда не отправляется. Результат по мере готовности пишется в
закрытое хранилище браузера для этого сайта, поэтому память не растёт, каким бы большим ни
был файл, а затем передаётся в загрузки. По той же причине это быстро на любом канале, и
нестабильная сеть не может прервать работу. Когда так и происходит, значок вверху страницы
говорит *Converts in your browser*.

Нужен современный Chrome, Edge, Firefox или Safari. В остальных браузерах страница
конвертирует на сервере: загрузка идёт потоком туда, результат потоком обратно
([как это устроено](privacy.md)). Чтобы выбрать это самим, добавьте к адресу
`?convert=server`. Приложение на вашем компьютере всегда конвертирует через свой локальный
сервер, который может занять все ядра.

![Завершённая конвертация](../images/convert.png)

## Что она принимает

- **Исходный `.zip` выгрузки** со своей схемой внутри (`DATA.0.TXT`).
- **Распакованную папку выгрузки**: перетащите её или нажмите *Choose folder*.
- **Отдельные файлы `DATA.N.BIN`** вместе с их `DATA.0.TXT`: выберите их разом, и они
  конвертируются как одна выгрузка.
- **`.BIN` совсем без схемы.** Откроется редактор схемы: введите поля вручную или вставьте
  их из SE11 или таблицы.

## Редактор схемы

*Edit schema* открывает поля в виде таблицы. Размер в байтах вычисляется из типа и длины,
если вы не зададите его сами, а итог внизу показывает, какой размер записи получается.
*Paste text* принимает целый `DATA.0.TXT` или короткие строки вроде `BUKRS C 4` и
`DMBTR P 7 2`. Отредактированная схема заменяет схему выгрузки для этой конвертации, а
*Download as DATA.0.TXT* сохраняет её на следующий раз.

![Редактор схемы](../images/schema-editor.png)

## Если записи не совпадают со схемой

Если схема не подходит к данным, страница говорит об этом словами, называет запись и поле,
на которых произошла ошибка, и перечисляет размеры записи, при которых данные читаются без
ошибок. Предложение применяется одним щелчком. В *More options* пункт *If a record will not
decode* позволяет вместо этого оставлять ошибочные значения пустыми и продолжать, подсчитывая
их.

## Параметры

| Параметр | |
|---|---|
| Amounts (суммы) | точные десятичные (по умолчанию) или числа с плавающей точкой |
| Record size | заменить размер записи, заданный схемой |
| Only the first N records | быстрая выборка |
| CSV delimiter | запятая, точка с запятой, табуляция или вертикальная черта; *CSV для Excel* выбирает точку с запятой там, где десятичный разделитель — запятая |
| Parquet compression | zstd (по умолчанию), snappy, gzip или без сжатия |
| Text shard encoding | для текстовых шардов `.TXT`; по умолчанию windows-1251 |
| One file per shard | zip-архив с отдельным файлом на каждый шард |

Для каждой конвертации страница также показывает равноценную команду `sap-bin` и `curl`,
которую можно скопировать.
