# Ничего не сохраняется

Веб-сервис устроен так, что случайно сохранить ваши данные он не может. В современном
браузере ваши данные до него даже не доходят.

## Конвертация в браузере

Там, где браузер это позволяет, страница конвертирует выгрузку сама, тем же движком,
скомпилированным в WebAssembly, и ничего не отправляет. Результат пишется в закрытое
хранилище браузера для этого сайта (другие сайты его прочитать не могут), передаётся в
загрузки и удаляется из хранилища при следующей конвертации или следующем визите. После
этого страница сообщает сервису итоги для его [статистики использования](#статистика-использования):
число записей и шардов, формат, один файл или несколько, имя таблицы SAP и затраченное
время. Никогда не сам файл, не имена полей и не значения. Браузерные тесты проверяют в
настоящем браузере, что, когда страница конвертирует сама, ни один запрос не несёт выгрузку
на сервер.

## Конвертация на сервере

Браузеры, которые так не умеют, и все, кто добавит к адресу `?convert=server`, конвертируют
на сервере:

- Загружаемый файл читается потоком и конвертируется по мере поступления, а результат
  потоком уходит обратно как загрузка. Страница отправляет файл частями по 8 МБ, и каждая
  часть принимается, только когда конвертер её забрал, поэтому сервер никогда не держит
  больше нескольких частей. Нет ни временных файлов, ни базы данных, ни кэша.
- В журнал попадают метод, путь, код ответа и длительность запроса. Никогда — строка запроса,
  имя файла, адрес или содержимое.
- Чтобы показывать ход работы, сервер хранит несколько счётчиков под случайным
  идентификатором, который выбрал ваш браузер, и удаляет их через пять минут после окончания
  конвертации. Загрузка, которая молчит десять минут, отменяется.
- Неудачная конвертация обрывает загрузку, поэтому неполный файл никогда не выглядит
  законченным.

## В обоих случаях

- Страница ничего не загружает с других сайтов, а её Content-Security-Policy запрещает ей
  обращаться к ним. Межсайтовые запросы отклоняются.
- Просмотрщик таблиц ([Perspective](https://perspective-dev.github.io)) отдаётся оттуда же.
  Часть своего кода он загружает по адресам `blob:`, которые политика страницы запрещает,
  поэтому он работает в собственном фрейме с политикой, которая их разрешает. Этот фрейм
  тоже не может обратиться ни к чему, кроме этого сайта, так что встроенный в Perspective
  необязательный ИИ-помощник и картографические тайлы ни с кем не свяжутся. Страница,
  которая держит ваши файлы, сохраняет строгую политику.

## Статистика использования

Сервис ведёт для своего оператора накопительные итоги:
- сколько было конвертаций и чем они закончились;
- сколько записей, шардов и байт сконвертировано;
- выходные форматы, пришла ли выгрузка одним файлом или несколькими, со страницы или через
  API, и имя таблицы SAP;
- те же итоги по дням за последние 90 дней и число открытий страницы;
- самая быстрая и самая большая конвертация.

Конвертации в браузере учитываются по итогам, которые сообщает страница, под клиентом
`browser`, и проверяются на правдоподобие.

Больше ничего. В статистике нет ни IP-адресов, ни user agent, ни имён файлов, ни имён полей,
ни значений, и ни одно число не связано с человеком. Имя таблицы учитывается, только если
оно похоже на имя таблицы SAP (`BSIS`, `/BIC/AZSALES00`); всё остальное считается как
`(other)`, поэтому текст, набранный в схеме, туда попасть не может.

Статистика закрыта. Она отдаётся только с токеном оператора (`SAPBIN_STATS_TOKEN`); без
токена её адресов просто нет. На диск она записывается, только если оператор указал файл
(`SAPBIN_STATS_FILE`), и этот файл — единственное, что сервис вообще пишет. Приложение на
вашем компьютере ничего не записывает и статистику не отдаёт.

## Это проверяется, а не просто заявляется

- CI запускает сервер под `strace` и падает, если во время конвертаций он открывает
  какой-либо файл на запись: [`scripts/prove-stores-nothing.sh`](../../scripts/prove-stores-nothing.sh).
  Второй прогон — с сохранением статистики в файл: этот файл должен быть единственным
  записанным и содержать только итоги.
- Образ Docker проверяется с корневой файловой системой только для чтения.
- Исходный код открыт. У скриптов страницы нет шага сборки: то, что лежит в `rust/web/`, —
  ровно то, что выполняет ваш браузер. Собирается только таблица стилей, из исходника на
  Tailwind CSS в `rust/web/styles/`, и CI проверяет, что закоммиченный результат ему
  соответствует.

## Самая надёжная гарантия

[Приложение](cli.md) запускает ту же страницу на вашем компьютере. Ваш файл никогда его не
покидает. Приложение отвечает только на `localhost`, что заодно закрывает атаки через
DNS rebinding с других сайтов.

[SECURITY.md](../../SECURITY.md) описывает, как запускать публичный экземпляр и как сообщить
об уязвимости (на английском).
